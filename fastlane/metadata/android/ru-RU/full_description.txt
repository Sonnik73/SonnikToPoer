Дневник силовых тренировок: работает без интернета, без рекламы и регистрации. Данные хранятся на телефоне; сеть — только по желанию: проверка обновлений на GitHub и резервные копии на ваш Google Диск.

<b>Тренировки</b>
<ul>
<li>Упражнения с любым сочетанием параметров: повторения, вес, время, расстояние, учёт собственного веса</li>
<li>Шаблоны тренировок и подбор шаблона на самые отдохнувшие мышцы</li>
<li>Цель на сегодня: +1 повтор к прошлой тренировке, а на верхней границе диапазона — следующий вес из вашего инвентаря</li>
<li>Таймер отдыха, который работает при заблокированном экране</li>
<li>Инвентарь: гантели, гири, резиновые эспандеры с сопротивлением «от–до», утяжелители</li>
<li>Техника выполнения для 63 упражнений по умолчанию</li>
</ul>
