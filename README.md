# SonnikToPower

Офлайн-приложение для Android, в котором удобно вести дневник тренировок и смотреть статистику прогресса.
Offline Android workout tracker with progress statistics (Russian and English UI).

## Возможности

- **Справочник упражнений.** Каждому упражнению выбираются измеряемые параметры в любом сочетании: повторения, вес отягощения, время, расстояние.
- **Учёт собственного веса.** Галочка «Учитывать собственный вес»: рабочий вес = вес тела + доп. вес. Подходит для подтягиваний, брусьев, отжиманий; отрицательный доп. вес — для упражнений с помощью.
- **Инвентарь.** Гантели, гири, грифы, утяжелители и резиновые эспандеры (сопротивление «от–до» и цвет).
  В подходе нужный снаряд выбирается одним нажатием, можно взять две резины сразу или пару гантелей («2 × 10 кг»).
  Для резины в статистику идёт пиковое сопротивление; режим «резина помогает» вычитает его из веса тела.
- **Шаблоны тренировок.** Набор упражнений с плановым числом подходов. Выбираете шаблон перед началом, а во время тренировки состав можно менять.
- **Тренировка в реальном времени.** Вес тела в начале занятия, подходы, разминочные подходы, подсказка «Прошлый раз» и автозаполнение значений.
- **История.** Все тренировки; любую можно открыть и исправить.
- **Статистика.**
  - По упражнению: старт, максимум, последний результат, прирост, лучший подход, расчётный максимум (1ПМ), объём, график динамики.
  - Общая: число тренировок, тоннаж, тренировки по неделям, график веса тела.
- **Резервная копия.** Экспорт всех данных в JSON-файл и восстановление из него.

## Установка

Готовый APK лежит в разделе [Releases](../../releases): каждая сборка ветки `main` публикуется автоматически.
Скачайте `SonnikToPower-*.apk` на телефон и установите (нужно разрешить установку из этого источника).
Новые версии ставятся поверх старых с сохранением данных, если задан ключ подписи (см. ниже).

## Сборка

- Kotlin, Jetpack Compose, Material 3, Room; minSdk 26 (Android 8.0).
- Локально: `./gradlew assembleRelease` (нужен Android SDK).
- CI: `.github/workflows/build.yml` — тесты, сборка, публикация релиза.

### Ключ подписи

Чтобы все сборки были подписаны одинаково, в настройках репозитория
(Settings → Secrets and variables → Actions) задаются секреты:

| Секрет | Значение |
|---|---|
| `SIGNING_KEYSTORE_BASE64` | файл keystore в base64 |
| `SIGNING_STORE_PASSWORD` | пароль хранилища |
| `SIGNING_KEY_ALIAS` | алиас ключа |
| `SIGNING_KEY_PASSWORD` | пароль ключа |

Без них APK подписывается временным ключом и не обновляет уже установленное приложение.

## Данные

Всё хранится локально в базе SQLite (Room). Схемы базы лежат в `app/schemas`, миграции проверяются тестом `MigrationTest`. У каждой записи есть UUID и время изменения —
это задел для будущей синхронизации с сервером.
